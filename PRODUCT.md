# Sentinel

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User specified React, TypeScript, Vite, Tailwind CSS, Cloudflare Pages and Pages Functions.

## Users

Website owners and operators with explicit permission to assess a target.

## Product Purpose

Register authorized targets, run bounded security checks, inspect genuine evidence and export reports.

## Capabilities and Constraints

Explicit hostname policies, public-address validation, authentication, quotas, cancellation, emergency stop, persistent history. No fabricated scan results. Isolated synthetic XSS and SQL labs. Network checks use a dedicated authenticated runner that pins DNS destinations. No credential attacks or destructive exploitation.

## Brand Commitments

Professional SOC-inspired dashboard; charcoal surfaces, subtle borders, restrained neon green and clean typography. Responsive sidebar and keyboard-accessible centered modals.

## Evidence on Hand

No live target or deployment credentials supplied. Initial metrics must be empty. Test fixtures are synthetic and labeled.

## Operating Context

User confirmed: single operator with a server-side access token. Multiple independent tenants are not implemented. Deployment and actual target assessment require operator configuration.

## Product Principles

- Show evidence and limitations together.
- Fail closed on authorization and unsafe destinations.
- Keep lab demonstrations separate from target findings.
- Never turn a failed or skipped check into a success.

## Accessibility & Inclusion

Keyboard-accessible dialogs, visible focus, readable contrast and responsive layouts.
